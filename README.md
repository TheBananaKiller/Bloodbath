# Basic Rundown

Bloodbath (apart from being a GD level) is a multiplayer first person shooter where users can easily make their own maps and levels. It is **Currently in V0.1 BETA** and barely works. In this README, I will document how it works, how to make your own levels (even without the editor, its easy!), and how to host your own servers and join them.

# Base
The base of this game is a simple first person shooter, not much more advanced than a template, in big and open maps players can explore and kill each other in. It uses WASD to move around, mouse to look, click to shoot, and space to jump. The basic controls we see everywhere. There is quite literally nothing special to say about the base.


# The Editor
As the Editor gets more advanced, I will make a whole documentation on how it works. For now, this will do.
The editor can be found in STTStuff in the Game folder. Its a simple editor where you can click to place objects on a grid. Then you can save it and name it map, and drop it into the Game folder and It will load the next time you play! Right click deletes or erases any square on the grid. We only have **Walls** and **Spawns** right now, sorry.

# How the editor works
The editor literally uses numbers and letters to represent the map. A very simple map could look like (Check Code for real example cause CBFDT):

1111111111111
1000000000001
1000000000001
10000S0000001
1000000000001
1000000000001
1111111111111

This generates a square, with 1s being walls and 0s being empty places. The S on the 4th row is the Spawn point. later on, 2 and 3 will most likely be different wall textures. Therefore, you could open up a notepad and just write out the map data and it would be easy.
